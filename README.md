# Sonsuz Varoluş Krizi Üretici

## Bu Ne Lan?

Bu, insanlık tarihinin en ciddi, en bilimsel ve en tamamen gereksiz projesidir.  
Amacı: Sana varoluşsal krizler üretmek. Gerçek, çalışan, absürt krizler.

### Nasıl Çalıştırılır?

```bash
python kriz_uretici.py
```

Evet, bu kadar. Sonsuz döngüde kriz üretir. Durdurmak istersen Ctrl+C bas ama kriz durmaz, sen durursun.

### Özellikler

- Tamamen Türkçe krizler
- 3 saniye düşünme süresi (bilimsel olarak optimize edildi)
- Sonsuz (evet, sonsuz)
- Hiçbir şey yapmaz ama her şeyi sorgular
- Patatesle alakası yoktur (bilerek)

### Neden Var?

Çünkü var olmak zorundaydı. Ya da değildi. Kim bilir?
